# Ember Coffee Roasters — Premium Specialty Coffee Platform

> **"Every Cup Starts with a Spark."**

Ember Coffee is an award-worthy, ultra-luxury specialty coffee e-commerce platform designed with an aesthetic inspired by Apple, Aesop, Blue Bottle Coffee, Linear, and Vercel.

---

## 🌟 Key Features

### 1. Award-Worthy Design & Storytelling
- **Cinematic Steam Animation**: Real-time canvas particle steam physics over hero coffee cup showcase.
- **Luxury Color System**: `#2C1810` Espresso, `#F7F3EE` Cream, `#C67C4E` Caramel, `#D6A85F` Gold, `#171717` Dark.
- **Editorial Typography**: *Playfair Display* serif headers matched with *Plus Jakarta Sans* body text.
- **Glassmorphism**: Backdrop blur cards, floating specs, and micro-interactions.

### 2. Full Storefront & Interactive E-Commerce
- **Landing Page**: 9 cinematic sections including Hero, Featured Micro-Lots, Why Ember cards, Best Sellers carousel, 5-stage interactive Coffee Journey timeline, Interactive Brewing Guide calculator with ratio slider, Connoisseur Testimonials, Pinterest-style Instagram gallery, and Newsletter subscription.
- **Shop Catalog**: Live instant search, category tabs (Single Origin, Signature Blend, Dark Roast, Espresso, Decaf, Gear), price range slider, roast profile filter, sorting, grid/list view toggle, wishlist hearts, and Quick View modals.
- **Product Details**: Multi-angle gallery, 360° interactive view rotator slider, flavor profile badges, weight selector (250g, 500g, 1000g), grind selector, brewing specs, verified customer reviews, and write review modal.
- **Cart & Checkout**: Slide-over drawer, promo code engine (`EMBER15`), free shipping progress bar, Stripe/Apple Pay style checkout flow with celebratory confetti.

### 3. Customer & Admin Dashboards
- **Customer Portal**: Order history with live 4-stage tracking status, saved wishlist, Ember Perks loyalty point balance & reward redemption, address book, and profile settings.
- **Executive Admin Portal**: Real-time revenue & sales charts, order status processor, product catalog CRUD modal (Add/Edit coffee beans, stock & prices), and coupon generator.

---

## 🛠️ Technology Stack

- **Core**: React 19, TypeScript, Vite, Tailwind CSS
- **Icons**: Lucide React Icons (`lucide-react`)
- **Animations**: Framer Motion (`framer-motion`), Canvas Confetti (`canvas-confetti`)
- **State Management**: React Context API with persistent LocalStorage synchronization

---

## 🚀 Quick Start Guide

```bash
# Install dependencies
npm install

# Run dev server locally
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.
